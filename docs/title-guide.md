# 标题与导语指南

本文件定义 Step 2 标题与导语轮及 Step 3 复核规则。目标是写出“克制编辑感 + 自然口语”的标题：准确、有作者判断、念起来顺，但不靠模板化反转、器官拟人或营销刺激。

---

## 最高优先级：忠实字幕

标题只能使用清洗字幕和终稿正文已经提供的对象、现象、数据、关系与结论。

- 先做字幕回指：为标题的每个实质判断指出字幕和正文中的直接支撑。
- 不得为了点击率新增因果、疗效、收益、风险、人物经历或确定性。
- 字幕说“可能、相关、初步发现”，标题不能升级成“导致、解决、证实、有效”。
- 外部资料不能成为标题素材；外部核验只负责标记字幕风险。
- 标题必须服务正文，不能先造一个强标题再迫使正文迁就。

标题选择优先级固定为：

1. 忠实字幕和终稿正文。
2. 保留证据边界。
3. 像真人编辑写出的自然中文。
4. 对具体读者有清楚的阅读理由。
5. 在不破坏前四项时自然覆盖搜索词。

搜索关键词不是硬性条件。关键词会让标题生硬、重复或扩大内容时，直接放弃关键词。

---

## 生成前先写内容锚点

候选标题之前，先读取 `article.plan.md`。标题必须从蓝图里的主问题、核心判断和读者入口生成；如果蓝图缺失或与草稿不一致，先回到内容初稿轮修正蓝图和草稿，不要直接套标题。

在标题生成前，基于 `article.plan.md` 再确认三项内容，不把过程写入 `article.draft.md`：

1. **可证明的核心判断**：用一句普通中文写清文章实际说明了什么。
2. **字幕证据锚点**：记录支撑该判断的原始对象、数字、现象或限定词。
3. **读者入口**：这个判断对应什么真实困惑、场景或选择；字幕没有提供的入口不得虚构。

如果核心判断仍是“X 很重要”“X 会产生影响”或“了解 X 很有意义”，说明主线还没提炼清楚，先返回正文，不要开始套标题。

---

## 六条候选语言路径

围绕同一个可证明判断生成 6 个候选，每个候选必须采用不同语言路径：

1. **直接判断**：像编辑给文章定题，直接说清最值得知道的判断。
2. **日常观察**：从字幕已经支持的生活场景、身体感受或具体动作进入。
3. **克制疑问**：只有正文确实回答了问题时才用问句；问句本身不暗示超出证据的答案。
4. **关键细节**：使用字幕已有的数字、对象、实验差异或反常现象。
5. **轻口语判断**：像作者向熟人解释这件事，允许自然语气，但不使用网络营销腔。
6. **编辑式概括**：信息完整、节奏简洁，不依赖悬念和情绪词。

同一批候选不得只替换同一模板中的名词。以下情况不算六条路径：

- 六个标题都以“为什么”开头。
- 六个标题都采用“X 不是 Y，而是 Z”。
- 只替换“关键、真正、核心、重要”等形容词。
- 把同一句话分别改成问号、冒号和破折号。

生成候选后隐藏“路径标签”进行盲选，避免因为某个类型看起来更吸睛而偏选。候选只用于内部比较，不写入最终文章，也不向用户要求选择。

---

## 混合风格标准

### 克制编辑感

- 标题先提供有效信息，再考虑好奇心。
- 使用具体名词和准确动词，少用抽象判断。
- 能一句说清就不拆成戏剧化的前后两句。
- 健康、医疗、法律、金融内容保留限定词，不承诺结果。

### 自然口语感

- 念出来像作者会对一个具体的人说的话，而不是发布会口号。
- 允许“总觉得、没那么简单、先别急”等自然表达，前提是字幕和正文支持。
- 口语词不能替代信息；删掉口语词后句子仍必须有明确判断。
- 不为了“接地气”把器官、算法、市场或抽象概念强行写成人。

两者冲突时，以准确和自然为准，不追求“更炸”。

---

## 默认淘汰的 AI 模板

以下结构具有明显批量生成感，默认淘汰。只有字幕语境证明它是最自然且不可替代的表达时才可保留，并在复核中说明理由：

- “为什么 X？问题不在 Y”或“为什么 X？靠的是 Y”。
- “X 不是 Y，而是 Z”“真正的 X，是 Y”“真正重要的不是 X”。
- “你的 X 正在 Y”“X 骗不了你的 Y”“身体比你更懂 X”等强行拟人。
- “从 X 到 Y”“一文读懂 X”“X 的底层逻辑”。
- “原来、竟然、没想到、比你想象中、悄悄、正在”等无事实贡献的刺激词。
- “揭秘、真相、密码、颠覆认知、权威解读、终极指南”。
- 只有抽象词的标题，如“重新理解身体与大脑的连接”。
- “N 个参数 / N 种方法 / N 个机制 / N 条原则 / N 个提醒 / N 个真相”。
- “数字 + 数字 + 数字：某某方案”，如“30 秒、5 分钟、30% 强度：静态拉伸的最优参数”。
- “最优参数、最佳方案、关键参数、完整方案、一套方案、科学方案、实用指南”等参数承诺式标题。
- “每周 X 分钟就能……”“每天 X 分钟改善……”“只要 X 就能 Y”等低成本强结果标题。

不要只删除模板词后保留原句架。例如把“真正决定睡眠的，不是意志力”改成“决定睡眠的并非意志力”，AI 感并没有消失，必须重新从核心判断生成。

健康科普标题优先从“读者误解、行动边界、具体困惑”出发，而不是从参数、数字、最佳方案出发。参数可以出现在导语或正文，但默认不做标题主骨架。

## 选择与真人感复核

先淘汰不忠实字幕、扩大证据或命中高风险模板的候选，再按以下顺序比较剩余标题：

1. **内容兑现**：读完正文后，标题中的每个判断都能找到明确支撑。
2. **自然程度**：不需要故意重读反转词、营销词或器官拟人才能成立。
3. **具体程度**：读者能看出文章讨论的对象、场景或问题。
4. **作者判断**：像作者对这份具体材料的取舍，不像标题生成器对主题的概括。
5. **传播和搜索**：只在前四项相当时比较。

最终候选必须逐项通过：

- **字幕回指**：标题的对象、关系、程度和限定词分别来自哪里？
- **去模板测试**：它是否只是常见句架换了一组名词？同批候选是否骨架雷同？
- **朗读测试**：正常语速读出来是否顺口，是否像人为拔高或故意制造悬念？
- **作者测试**：换一篇同类文章后，这个标题是否还能直接套用？能套用就太泛。
- **删除刺激词测试**：去掉问号、冒号、反转词或情绪副词后，是否仍有有效信息？

若 6 个候选都不自然，重新提炼“可证明的核心判断”，不要继续在原候选上换词。

---

## 标题硬要求

- 不超过 32 个字符，包含标点。
- 不使用 emoji。
- 不使用“震惊、必看、不看后悔、速转、建议收藏、普通人必看”。
- 不使用“最优、最佳、完整、科学方案、关键参数、有效对抗、显著提升”等会把文章推向承诺或课程感的词。
- 不堆砌 SEO 关键词。
- 不把相关性写成因果，不把可能性写成确定结果。
- 不把多个研究数字合并成标题判断，不把综述平均效果、单项研究参数和日常方案写成同一个承诺。
- 不编造个人经历、粉丝反馈、读者症状或字幕没有的数据。

## 小标题复核

编辑终稿轮必须同时检查小标题。小标题不写入 frontmatter，但会强烈影响真人感；以下小标题默认重写：

- “N 个机制 / N 个参数 / N 个提醒 / N 种方式”。
- “关键参数：时间、频率和强度”。
- “实用方案 / 最优方案 / 完整方案 / 可以带走的做法”。
- “不只是身体：……”这类泛化拔高句。

小标题应优先写成读者问题或判断边界，例如：

- AI 腔：`三个参数：30秒、5分钟、每周5天`
- 编辑感：`30 秒、每周 5 分钟，是一个很实用的起点`
- AI 腔：`两则来自实验室的提醒`
- 编辑感：`瑜伽和疼痛耐受：别急着神化`

自动校验只能拦截长度、禁用词和部分高频句架，不能证明标题已经像真人。通过脚本后仍必须完成上述语义复核。

---

## 写入与 Step 3 复核

Step 2 自动选择最优候选，将标题和导语写入 `article.draft.md`：

```md
---
title: 最终标题
description: 30 字以内导语
author: 身心漫游
---
```

导语补充标题没有覆盖的最强信息点，不重复标题，不超过 30 字，也不得超出字幕边界。导语和标题同样受事实边界约束：不得把多个研究合并成确定方案，不得补具体天数、频率、效果或“最有效起点”，不得暴露“播客/视频/字幕/主讲人”等来源形式。

真人化改写和收尾完成后，Step 3 必须重新复核标题与终稿：

- 标题、导语、开头、结尾是否指向同一个核心判断。
- 终稿删改后，标题是否仍能完成字幕回指。
- 标题是否因为追求自然口语而扩大了字幕结论。
- 是否在改稿过程中又落回问句、反转、拟人等高频模板。

若 Step 3 修改标题或导语，重新执行终稿一致性检查和配图提示词映射检查后才能进入 Step 4。
