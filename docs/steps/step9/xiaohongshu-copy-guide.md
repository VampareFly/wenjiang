# 小红书文案与去 AI 味指南

本文件定义 Step 9。基于 `article.md`、`article.plan.md`、`source.cleaned.txt` 和 `xiaohongshu-strategy.json` 生成 `小红书文案.txt`。

## 两轮生成

### 第一轮：平台文案

- 第一行是标题，不超过 20 字。
- **文案字数硬约束**：**全文总字数严格控制在 1000 字以内（含标题、正文、长文引导与标签）**，推荐 400~800 字，短小精悍，适合移动端快速阅读与滑屏。
- **必须采用小红书爆款标题 5 大公式之一**（根据文章自动选取最契合的模式，不需向用户过问）：
  1. **反直觉认知冲突型**：`《难怪你……原来根源在这！》` `《越……反而越……》`（例：*《越节食肚子反而越大？皮质醇正在疯狂囤油》*）；
  2. **场景化扎心代入型**：`《吃完饭秒变特困生……》` `《四肢纤细单单长肚子……》`（例：*《天天靠咖啡续命？难怪你下午 3 点断崖式虚脱》*）；
  3. **惊叹避坑与警告型**：`《求求别盲目……了》` `《千万别单吃……》`（例：*《求求别盲目补 D3 了！单吃不加它变血管斑块》*）；
  4. **顶级权威背书型**：`《斯坦福终于把……说明白了》` `《几十项人体试验告诉你……》`（例：*《别再被伪科普洗脑了！几十项试验拆解植物油》*）；
  5. **低门槛逆袭自救型**：`《改 1 个小习惯……》` `《饭前加这一步……》`（例：*《饭前一勺苹果醋：不用戒碳水，餐后血糖稳降》*）。
- 主关键词自然出现在标题或正文前 120 字内。
- 开头直接进入具体痛点、误解、扎心场景或反差判断，不写“今天我们来看看”“抛开情绪化言论”。
- 只选一个传播切口，不把公众号长文压缩成四条对称摘要。
- 可以使用列表，但不默认使用 `1️⃣ 2️⃣ 3️⃣ 4️⃣`、完全相同的“术语：解释”句式。
- 结尾给低压力提醒或行动边界，添加 3–6 个真实相关热搜话题标签。

### 第二轮：独立健康表达与去 AI 质检

重新读取字幕、文章、策略和第一轮文案，按以下顺序复核：

1. 标题、数字、机制、建议能否回指字幕或 `article.md`。
2. 是否把可能写成确定、相关写成因果、初步证据写成成熟结论。
3. 是否新增个人经历、粉丝反馈、症状、疗效、剂量或适用人群。
4. 是否出现机械四点式、对称句、空泛冲突、伪口语或固定引流模板。
5. 标题、首段、卡片封面和主关键词是否指向同一个问题。

发现问题时只做局部修改，不重写已经合格的事实段。

## 健康表达硬门禁

下列词语默认触发回查和降级，除非字幕明确支持同等强度且不构成医疗承诺：

- 完全安全、保证有效、根治、逆转、科学清除；
- 坚决截止、修复窗口、暴击受体、潜伏在身体里；
- 直接驱动、必然导致、彻底改变、重新掌控；
- 把机制假设写成行动效果，把生物标志物变化写成临床获益。

需要表达建议时优先写“可以考虑”“一个较稳妥的起点”“不等于适合所有人”。涉及疾病、药物、停药或特殊人群时保留专业建议边界。

## 去 AI 味硬门禁

- 禁止“底层逻辑、完整真相、颠覆认知、今天我们抛开情绪化言论”。
- 禁止“这篇只是把……拎了出来”作为固定结尾。
- 不用刺激词代替信息，不用 emoji 数字制造虚假结构感。
- 真人感来自具体对象、明确判断、自然取舍和句子节奏，不来自编造第一人称经历。
- 不把每篇文案都写成“开场冲突 → 四点摘要 → 三行引流 → 标签”的同一骨架。

## 条件式长文引导

读取策略中的 `cta_mode`：

- `omit`：不出现主页、完整版、长文或“去翻一下”等引导。
- `include`：只写 1–2 句自然引导，不使用 `⚠️` 固定开头，不超过 60 字；必须指出长文真实增加的内容。

可用表达方向，不得逐篇照抄：

```text
这篇先说结论，证据怎么一步步推到这里，我放在主页里的同名长文了。

想继续看研究边界，可以翻一下主页里的同名长文。
```

禁止固定句：

```text
完整版我写在同名主页那篇长文里了，想……的去翻一下 📖
```

全篇仍不得出现“公众号、二维码、微信、加V”等硬引流词。
