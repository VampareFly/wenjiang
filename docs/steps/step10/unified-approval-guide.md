# 统一预览确认指南

本文件定义 Step 10。此步骤不生成新内容，只让用户统一检查公众号、小红书与今日头条正式资产。

必须预览：

- `article.html`：公众号内容、排版和正文图片；
- `cover.png` 与 `配图N.png`；
- `小红书卡片-{01-N}.png`；
- `小红书文案.txt`；
- `今日头条文章.md`（含 3 个三段式标题候选）；
- `微头条.txt`；
- `toutiao-cover-{1-3}.png`（头条专属爆款三图封面）。


Agent 必须停在本步骤。初始生成请求不等于上传授权；只有当前对话中用户明确确认，才能运行：

```bash
python3 scripts/workflow_state.py approve articles/<YYYYMMDD-HHMMSS>
```

确认前会重新校验小红书策略与各项检查记录；确认摘要覆盖文章、HTML、公众号图片、全部小红书卡片、小红书文案与今日头条资产。任一正式资产在确认后变化，确认立即失效。

用户要求修改时，`reopen` 到实际产生问题的步骤：公众号排版回到 Step 6，小红书策略回到 Step 7，卡片回到 Step 8，文案与头条资产回到 Step 9。
