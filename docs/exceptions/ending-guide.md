# 结尾与免责声明指南

本文件定义 Step 2 收尾阶段的免责声明、关注引导和结尾边界。只在 `article.draft.md` 提升为最终 `article.md` 前处理文末内容时读取。

---

## 收尾原则

文章结尾必须回到本文核心判断，不用空泛金句替代结论。

- 收尾部分应给出克制判断、行动边界或未解问题。
- 健康、医疗、法律、金融等专业内容必须保留证据边界。
- 关注引导可以有，但不能压过文章本身，也不能制造焦虑或承诺效果。

---

## 免责声明

涉及医疗、法律、金融等专业领域，文末必须有免责声明：

- 使用 `>` 引用格式。
- 控制在 2 句以内，约 50 字。
- 合并“来源说明 + 参考边界 + 专业决策提示”，不要展开成长段。
- 没有明确来源时，使用“本文基于公开资料整理，仅供科普参考”。

模板：

```md
> 本文整理自 [来源] 的相关内容，仅供科普参考。涉及 [领域] 等，请咨询对应专业人士。
```

---

## 关注引导

免责声明后可以生成一段很轻的关注引导，40-70 字。它必须像文章自然结束后的一句轻提示，不像广告、栏目介绍或自我介绍。

关注引导不是强制产物，但省略时必须是有意识判断，而不是遗漏。生成 `article.md` 后必须软检查：

- 如果文章属于健康科普、个人成长、生活方式等适合自然收尾的内容，建议在免责声明后加入关注引导。
- 如果未生成关注引导，进入下一步前必须自检：是否有明确理由省略？
- 若没有明确理由，默认补上一段低压力关注引导。

### 核心铁律：主题强相关与内容锚定

**关注引导必须与当前文章探讨的核心领域强绑定，严禁“文不对题”！**
例如：文章讨论睡眠与生物钟，引导绝不能写“我会继续拆解控糖和内脏脂肪”；文章讨论肠道与抗炎，引导绝不能写“我会继续分享专注力与大脑训练”。

### 分类场景与推荐话术库

1. **代谢 / 控糖 / 饮食顺序 / 减脂类文章**：
   - *推荐*：“我会继续把关于代谢、食欲和饮食结构的扎实研究，尽量讲成普通人能用来改善日常饮食的大白话。讲清楚原理，也讲清楚边界。感兴趣的话，可以关注「食外」。”
2. **睡眠 / 昼夜节律 / 精力管理类文章**：
   - *推荐*：“我会继续追踪昼夜节律、睡眠医学与神经生物学的前沿研究，用大白话拆解如何不靠硬熬调好生物钟、找回白天好精力。感兴趣的话，可以关注「食外」。”
3. **肠道微生态 / 慢性炎症 / 超加工食品类文章**：
   - *推荐*：“类似肠道屏障、慢性炎症和日常三餐的底层关联，我会尽量不讲玄学，只讲证据支持的饮食与生活边界。感兴趣的话，可以关注「食外」。”
4. **细胞自噬 / 间歇性断食 / 长寿医学类文章**：
   - *推荐*：“我会继续把全球顶尖长寿医学与细胞抗衰的科学进展，翻译成日常能落地的小习惯。讲清结论，也讲清适用人群。感兴趣的话，可以关注「食外」。”
5. **综合交叉 / 泛健康通用兜底（无明显单一垂直主题时使用）**：
   - *推荐*：“关注「食外」，我们用扎实的科学证据与前沿机制解析，带你穿透身体表象，掌握重塑身心活力的底层科学。”

### 禁忌事项

- 严禁“文不对题”的脱节引导（如睡眠文引导控糖，断食文引导情绪管理）；
- 严禁承诺式夸大，如“关注我包你瘦”“少走弯路”“带你根治……”；
- 严禁空泛套话，如“本账号持续输出优质内容”“健康顾问”；
- 头条/小红书严禁出现跨平台词汇（如“公众号”“微信”）。
