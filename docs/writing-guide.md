# 写作指南

本文件定义 `article.md` 的生成规则：内容识别、主线组织、标题导语、正文写法、免责声明、关注引导和终稿检查。

---

## 内容类型

横跨多类型时，以占比最高的类型为准。

| 类型 | 判断特征 | 写作重点 |
| --- | --- | --- |
| 健康科普 | 医学数据、研究数据、身体机制 | 数据开场、颠覆常识、机制解释、实操边界 |
| 财经商业 | 市场分析、创业故事、投资逻辑 | 观点清晰、逻辑递进、有争议性 |
| 科技前沿 | 技术原理、产品测评、未来趋势 | 场景化描述、强对比、有预判 |
| 个人成长 | 经验分享、认知升级、方法论 | 共鸣感、行动指南、金句 |
| 户外探险 | 自然环境、技能展示、冒险经历 | 画面感、临场感、代入感 |
| 文化历史 | 人物故事、历史事件、文化现象 | 叙事感、细节、反思 |
| 生活技能 | 操作方法、工具使用、实用技巧 | 步骤清晰、直接实用 |
| 访谈对话 | 嘉宾观点、争论碰撞 | 观点提炼、金句呈现、冲突感 |

## 生成流程

文章不能一次性从字幕直接写成终稿，必须分两轮完成：

1. **内容初稿轮**：提炼主线、取舍素材、选择开头，生成结构完整、忠实字幕的初稿。
2. **真人化改写轮**：逐段重写 AI 味明显的表达，不新增事实、不改变结论，只优化开头、节奏、判断、细节和口语感。

最终写入 `article.md` 前必须完成真人化改写；格式化 Markdown 或 HTML 阶段不负责补救文章的 AI 味。

---

## 事实与视角

- 文章必须以作者视角书写，不能暴露“我在转述一个视频/播客”。
- 核心观点、事实、数据、案例必须来自字幕内容；可以压缩、合并、换顺序，但不能脱离原意另起炉灶。
- 可以用常识性背景补充连接，但不能编造研究、数字、人物经历、名人名言或原视频没有的结论。
- 引用学者或机构时，直接写“斯坦福的 Nirao Shah 发现……”，不要写“Huberman 提到……”。
- 涉及医疗、法律、金融等专业领域，必须保留证据边界，不把科普写成确定建议。

禁止：

- 提及原视频主讲人名字，除非其身份本身就是文章主题。
- 使用“视频中提到”“播客里讲到”“今天的节目”等来源暴露表达。
- 用“听懂这个案例”“下一期我们会”等视频/播客口吻。

## 主线与结构

生成正文前，先用一句话写清楚本文要证明或解释的核心判断，再围绕它取舍素材。

- 阅读路径优先采用：问题/冲突 -> 关键解释 -> 证据或案例 -> 对中国读者的意义 -> 行动建议。
- 每个小节只服务一个功能：提出冲突、解释机制、补充证据、给出判断或落到行动。
- 正文不是字幕摘要，不按字幕时间顺序机械复述。
- 每段都要回答上一段留下的问题，或自然带到下一层信息。
- 同一概念不要分散反复解释；第一次讲清楚，后文只推进或回扣。
- 每讲一个专业机制，都要落到中国读者熟悉的生活场景、身体感受、消费选择或行动判断上。
- 标题、导语、开头、正文结尾必须指向同一个核心判断。

---

## 标题与导语

### 标题

生成 5 个候选标题后，AI 自动选择最优标题写入 frontmatter 的 `title` 字段，并从正文中删除候选列表。

选择标准：微信搜一搜关键词覆盖 > 认知冲突感 > 具体结论或数字 > 社交传播性。

标题要求：

- 包含具体结论、数字或强信息点。
- 制造好奇心、颠覆常识或强烈共鸣。
- 至少覆盖 1 个搜索热词。
- 不向用户展示候选列表，不要求用户选择。

### 导语

导语控制在 30 字以内，包含核心冲突或最强信息点，用于朋友圈转发。

---

## 开头

正文前三句话必须进入正题，完成以下任务：

- 抛出冲突、痛点、反常识判断或强画面。
- 承接标题制造的好奇心和关键词。
- 给读者一个继续读下去的理由。

优先开头方式：

| 素材特征 | 写法 |
| --- | --- |
| 有明确反常识结论 | 第一句直接推翻常见认知，第二句给出依据或代价 |
| 和读者痛点强相关 | 直接写身体感受、消费困惑或行动难题 |
| 有画面感案例 | 从具体瞬间切入，不先解释大道理 |
| 有短促冲突原话 | 把最有爆点的一句话提前，但不暴露来源 |
| 标题悬念强 | 第一句直接回应标题疑问 |
| 以上都不明显 | 用读者心里已有的问题开场 |

禁止用“今天我们来聊聊”“这期内容主要讲”“在现代社会”铺垫；禁止先讲一大段概念定义。

---

## 正文

正文 1500-2000 字，不含关注引导。

- 开篇 0-300 字：最强信息点直接开场。
- 展开 300-1000 字：核心内容 + 本土化场景。
- 深化 1000-1500 字：背后逻辑 + 记忆点。
- 收尾 1500-2000 字：回到主线，给出结论或行动建议。

排版要求：

- 每段不超过 3 行，适合手机阅读。
- 重要信息或金句用 `**加粗**`。
- 引用原话使用「」。
- 在适合位置标注正文配图：`【配图N：标题】`，标题 6-12 字，编号与 `cover_prompt.md` 一一对应。图片提示词和封面规范见 `docs/image-guide.md`。

## 免责声明

涉及医疗、法律、金融等专业领域，文末必须有免责声明：

- 使用 `>` 引用格式。
- 控制在 2 句以内，约 50 字。
- 合并“来源说明 + 参考边界 + 专业决策提示”，不要展开成长段。
- 没有明确来源时，使用“本文基于公开资料整理，仅供科普参考”。

模板：

```md
> 本文整理自 [来源] 的相关内容，仅供科普参考。涉及 [领域] 等，请咨询对应专业人士。
```

## 关注引导

免责声明后可以生成一段很轻的关注引导，40-70 字。它必须像文章自然结束后的一句轻提示，不像广告、栏目介绍或自我介绍。

关注引导不是强制产物，但省略时必须是有意识判断，而不是遗漏。生成 `article.md` 后必须软检查：

- 如果文章属于健康科普、个人成长、生活方式等适合自然收尾的内容，建议在免责声明后加入关注引导。
- 如果未生成关注引导，进入下一步前必须自检：是否有明确理由省略？
- 若没有明确理由，默认补上一段低压力关注引导。

写法：

1. 从本文讨论的身体信号、日常选择或科学边界自然延伸。
2. 用“我会继续把……讲清楚”这类低姿态表达说明写作方向。
3. 可用“感兴趣的话，可以关注”收尾，不制造焦虑、稀缺感或行动压力。

禁止：

- “少走弯路”“别再踩坑”“我踩过的坑不想你再踩”。
- “关注我，带你……”“跟着我……”“我来帮你……”。
- “健康顾问”“专业导师”“长期陪伴你”。
- “这个号”“本账号”“这里会持续输出”“健康内容”“科普内容”等账号简介式表达。
- 暗示关注后能获得健康改善、避免疾病或做出正确选择。

推荐写法：

- 我会继续把这些和身体有关的研究，尽量讲成普通人能用来判断日常选择的话。讲清楚结论，也讲清楚边界。
- 类似睡眠、饮食、代谢这些问题，我会尽量不讲玄学，也不讲绝对答案，只讲证据能支持到哪里。

---

## 输出规范

- 输出为 markdown 文件。
- 全中文，英文术语附中文解释。
- 忠实原内容，不夸大、不捏造数据。
- 同时临时输出 `cover_prompt.md`，图片提示词格式见 `docs/image-guide.md`。
- 读者读完后，应能用一句话复述“这篇文章在讲什么、为什么重要、我该怎么做”。

---

## 去 AI 味终稿检查

输出 `article.md` 前，必须逐段检查并重写以下问题：

- **只总结，不推进**：读完知道“很重要”，但不知道重要在哪里。
- **只解释，不表态**：信息都对，但作者没有判断。
- **只抽象，不落地**：全是“认知、系统、能力、影响、价值”，没有场景和细节。
- **只平衡，不取舍**：每句话都正确、中性、保险，但没有锋芒。
- **假口语**：频繁使用“说白了”“你会发现”“真的很重要”，但句子仍然空泛。

改写优先级：

1. 补具体对象：从“人们”改成“熬夜到两点的人”“每天久坐的上班族”。
2. 补真实场景：从“影响健康”改成“早上醒来头重、下午靠咖啡硬撑”。
3. 补作者判断：从“值得关注”改成“这件事最麻烦的地方是……”。
4. 补句子节奏：长句拆短，关键判断单独成段。
5. 删正确废话：不能服务主线的概念句、套话句、过渡句直接删。

必须避免：

- “总的来说”“综上所述”“不难发现”“值得注意的是”“毋庸置疑”。
- “接下来让我们”“首先……其次……最后……”“令人惊叹的是”“不得不说”。
- “作为一个……”“在当今社会”“随着……的发展”“我们不妨”。
- “希望本文对你有所帮助”“记得点赞转发哦”。
- 用“一、二、三”或“第一点、第二点”做硬性分段。
- 内容中使用 emoji。

健康科普额外要求：

- 数据充分时可以直接下判断；数据初步时必须使用“初步”“有一定证据”“数据还不够成熟”等限定词。
- 证据不足时，不能给出强硬个人行动建议。
- 优先强调证据、机制、边界、日常选择，不使用“避坑”“逆袭”“改变命运”等转化词。

终稿确认：

- 开头前三句话有冲突、痛点、画面或反常识。
- 每个小节至少有一句明确判断。
- 每 300 字左右至少出现一次具体场景、数字、身体感受、消费选择或行动判断。
- 标题、导语、开头、结尾指向同一个核心判断。
- 没有为了口语化而机械堆叠口头禅。
