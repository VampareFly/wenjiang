# 写作指南

本文件定义 Step 2 的核心写作规则：内容识别、事实边界、主线组织、开头正文写法和配图标记。标题选择、文末收尾和终稿检查已拆到专项文档：

- 标题与导语：`docs/title-guide.md`
- 免责声明和关注引导：`docs/ending-guide.md`
- 终稿检查入口：`docs/final-writing-check.md`

---

## 内容类型

横跨多类型时，以占比最高的类型为准。

| 类型 | 判断特征 | 写作重点 |
| --- | --- | --- |
| 健康科普 | 医学数据、研究数据、身体机制 | 数据开场、颠覆常识、机制解释、实操边界 |
| 财经商业 | 市场分析、创业故事、投资逻辑 | 观点清晰、逻辑递进、有争议性 |
| 科技前沿 | 技术原理、产品测评、未来趋势 | 场景化描述、强对比、有预判 |
| 个人成长 | 经验分享、认知升级、方法论 | 共鸣感、行动指南、有记忆点的判断 |
| 户外探险 | 自然环境、技能展示、冒险经历 | 画面感、临场感、代入感 |
| 文化历史 | 人物故事、历史事件、文化现象 | 叙事感、细节、反思 |
| 生活技能 | 操作方法、工具使用、实用技巧 | 步骤清晰、直接实用 |
| 访谈对话 | 嘉宾观点、争论碰撞 | 观点提炼、金句呈现、冲突感 |

## 生成流程

文章不能一次性从字幕直接写成终稿。核心写作必须先产出内容初稿，再生成正式标题和导语，最后进入真人化改写：

1. **内容初稿轮**：提炼主线、取舍素材、选择开头，生成结构完整、忠实字幕的初稿。
2. **标题与导语轮**：按 `docs/title-guide.md` 基于初稿生成正式标题和导语，写入 `article.md` frontmatter。
3. **真人化改写轮**：先按 `docs/final-writing-check.md` 做硬检查，再按 `docs/ai-humanizer-guide.md` 逐段重写 AI 味明显的表达。不新增事实、不改变结论，只优化开头、节奏、判断、细节、口语感和作者判断。

最终写入 `article.md` 前必须完成真人化改写；格式化 Markdown 或 HTML 阶段不负责补救文章的 AI 味。

## 事实与视角

- 文章必须以作者视角书写，不能暴露“我在转述一个视频/播客”。
- 核心观点、事实、数据、案例必须来自字幕内容；可以压缩、合并、换顺序，但不能脱离原意另起炉灶。
- 可以用常识性背景补充连接，但不能编造研究、数字、人物经历、名人名言或原视频没有的结论。
- 引用学者或机构时，直接写“斯坦福的 Nirao Shah 发现……”，不要写“Huberman 提到……”。
- 涉及医疗、法律、金融等专业领域，必须保留证据边界，不把科普写成确定建议。

禁止：

- 提及原视频主讲人名字，除非其身份本身就是文章主题。
- 使用“视频中提到”“播客里讲到”“今天的节目”等来源暴露表达。
- 用“听懂这个案例”“下一期我们会”等视频/播客口吻。

## 主线与结构

生成正文前，先用一句话写清楚本文要证明或解释的核心判断，再围绕它取舍素材。

- 阅读路径优先采用：问题/冲突 -> 关键解释 -> 证据或案例 -> 对中国读者的意义 -> 行动建议。
- 每个小节只服务一个功能：提出冲突、解释机制、补充证据、给出判断或落到行动。
- 正文不是字幕摘要，不按字幕时间顺序机械复述。
- 每段都要回答上一段留下的问题，或自然带到下一层信息。
- 同一概念不要分散反复解释；第一次讲清楚，后文只推进或回扣。
- 每讲一个专业机制，都要落到中国读者熟悉的生活场景、身体感受、消费选择或行动判断上。
- 标题、导语、开头、正文结尾必须指向同一个核心判断。内容初稿可以先确定标题方向，但进入真人化改写和终稿检查前，必须先按 `docs/title-guide.md` 生成正式标题和导语。

## 开头

正文前三句话必须进入正题，完成以下任务：

- 抛出冲突、痛点、反常识判断或强画面。
- 内容初稿阶段先承接标题方向；正式标题和导语生成后，真人化改写轮必须回头调整开头，使其承接标题制造的好奇心和关键词。
- 给读者一个继续读下去的理由。

优先开头方式：

| 素材特征 | 写法 |
| --- | --- |
| 有明确反常识结论 | 第一句直接推翻常见认知，第二句给出依据或代价 |
| 和读者痛点强相关 | 直接写身体感受、消费困惑或行动难题 |
| 有画面感案例 | 从具体瞬间切入，不先解释大道理 |
| 有短促冲突原话 | 把最有爆点的一句话提前，但不暴露来源 |
| 标题悬念强 | 第一句直接回应标题疑问 |
| 以上都不明显 | 用读者心里已有的问题开场 |

禁止用“今天我们来聊聊”“这期内容主要讲”“在现代社会”铺垫；禁止先讲一大段概念定义。

## 正文

文章全文长度以完读率优先，包含正文、免责声明、关注引导等所有内容。

- 普通知识型文章控制在 1500-2000 字。
- 如果原视频信息密度低，宁可写到 1200-1500 字，也不要注水。
- 如果内容复杂，最多放宽到 2000 字，但必须保证每 300 字都有新信息或新判断。
- 关注引导和免责声明也计入全文长度，不能为了补充固定模块而拖长文章。

- 开篇约 300 字内：最强信息点直接开场。
- 展开部分：核心内容 + 本土化场景。
- 深化部分：背后逻辑 + 记忆点。
- 收尾部分：回到主线，给出结论或行动建议，并为必要的免责声明和关注引导留出空间。

排版要求：

- 每段不超过 3 行，适合手机阅读。
- 只对事实、数字、核心判断少量使用 `**加粗**`；不要机械加粗空泛金句、列表标题或情绪化口号。
- 引用原话使用「」。
- 在适合位置标注正文配图：`【配图N：标题】`，标题 6-12 字，编号与 `cover_prompt.md` 一一对应。图片提示词和封面规范见 `docs/image-prompt-guide.md`。
