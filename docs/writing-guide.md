# 写作指南

本文件定义文章生成阶段的内容识别、写作策略、结构组织、排版要求和去 AI 味规则。

---

## 内容类型识别

| 内容类型 | 判断特征 | 对应文章风格 |
|---------|---------|------------|
| 健康科普 | 医学数据、研究数据、身体机制 | 数据开场、颠覆常识、实操建议 |
| 财经商业 | 市场分析、创业故事、投资逻辑 | 观点犀利、逻辑清晰、有争议性 |
| 科技前沿 | 技术原理、产品测评、未来趋势 | 场景化描述、对比强烈、有预判 |
| 个人成长 | 经验分享、认知升级、方法论 | 共鸣感强、金句密集、有行动指南 |
| 户外探险 | 自然环境、技能展示、冒险经历 | 画面感强、临场感、带入感 |
| 文化历史 | 人物故事、历史事件、文化现象 | 叙事感强、有细节、有反思 |
| 生活技能 | 操作方法、工具使用、实用技巧 | 步骤清晰、直接实用、省时省力 |
| 访谈对话 | 嘉宾观点、对话交流、争论碰撞 | 观点提炼、金句呈现、有冲突感 |

横跨多类型时，以占比最高的为准。

---

## 写作策略

- **主题**：找到所有内容的统一核心
- **主线**：一条逻辑线索串联所有信息点
- **亮点**：每个切片贡献 1-2 个最有价值的信息点
- **SEO词**：根据类型选 2-3 个微信搜一搜高频词
- **社交钩子**：设计一句让人想转发的金句或数据

---

## 视角管理（强制执行）

文章必须以**作者视角**书写，不能暴露"我在转述一个视频/播客"的事实。

**绝对禁止**：
- 提及原视频主讲人名字（如"Huberman说……""Huberman本人也觉得……"）
- 暴露内容来源（如"视频中提到……""播客里讲到……""节目中……"）
- 播客/视频特有用语（如"听懂这个案例""今天的节目""下一期我们会……"）

**正确做法**：
- 把字幕内容内化为自己的知识，以"我知道/我发现/有意思的是"的口吻讲述
- 引用学者观点时，直接说"斯坦福的Nirao Shah发现……"，不要说"Huberman提到Shah发现……"
- 数据和案例作为"众所周知的事实"或"我查到的有趣研究"来呈现，而非"视频里引用的数据"

## 结构重组与连贯性校准

生成正文前，先把字幕内容重组为一条读者能顺着读下去的文章线索：

- **忠实字幕**：核心观点、事实、数据、案例必须来自字幕内容；可以压缩、合并、换顺序，但不能脱离原意另起炉灶
- **合理取舍**：删掉寒暄、重复、口误和旁枝信息，保留对文章主题有推动作用的内容
- **结构先行**：先确定"问题/冲突 → 关键解释 → 证据或案例 → 对中国读者的意义 → 行动建议"的阅读路径，再写正文
- **段落递进**：每一段都要回答上一段留下的问题，或把读者自然带到下一层信息；禁止把字幕要点生硬拼接成清单
- **过渡自然**：跨主题、跨案例、跨机制时必须写出承接句，说明两段之间的关系
- **概念收束**：同一概念不要分散在多个地方反复出现；第一次讲清楚，后文只做推进或回扣
- **读者视角**：每讲一个专业机制，都要落到一个中国读者熟悉的生活场景、身体感受、消费选择或行动判断上
- **文学性要求**：文章要有开合、节奏和回环；开头提出的冲突，正文逐步拆解，结尾必须回到主线，不要突然收住

## 内容生成规则

### 爆款标题（5个）
- 每个标题包含具体结论或数字
- 制造好奇心、颠覆常识或强烈共鸣
- 至少含一个搜索热词
- 附一句适用读者说明

### 导语（30字以内）
包含核心冲突或最强信息点，用于朋友圈转发。

### 正文（1500-2000字）

结构节奏：
- 开篇 0-300字：最强信息点直接开场
- 展开 300-1000字：核心内容 + 本土化场景
- 深化 1000-1500字：背后逻辑 + 社交金句
- 收尾 1500-2000字：结论或行动建议（不含关注引导，关注引导单独输出）

连贯性要求：
- 正文不是字幕摘要，不按字幕时间顺序机械复述；必须按文章主线重新组织
- 每个小节只能服务一个明确功能：提出冲突、解释机制、补充证据、给出判断或行动建议
- 小节之间要有逻辑桥，避免"上一段还在讲A，下一段突然跳到B"
- 标题、导语、正文开头、正文结尾必须指向同一个核心判断，不能各讲各的
- 如果字幕信息不足以支撑某个判断，可以用常识性背景补充连接，但不能编造研究、数字、人物经历或原视频没有的结论

排版规范：
- 每段不超过3行，适合手机阅读
- 重要信息或金句**加粗**
- 引用原话使用「」

WeChat HTML 技术约束：
- 禁止使用 flex `gap` 属性（公众号不支持），卡片间距用 `margin-bottom` 实现
- 禁止使用 `<style>` 标签，所有样式必须为 inline style
- 标题不放在卡片内，单独作为顶部元素或由公众号后台自动处理
- 在适合配图位置标注【配图N：标题】，N为编号，标题6-12字
- 配图编号与 cover_prompt.md 中的提示词 section 一一对应
- 配图2-4张为宜，封面1张，总计 N+1 条提示词临时输出到 cover_prompt.md，图片生成完成后删除该文件
- 封面图必须为横向 16:9，与正文配图比例一致；主体完整居中，关键元素不要贴边，避免公众号封面裁切后展示不完整

### 关注引导（紧跟免责声明之后，独立段落）

正文和免责声明结束后，生成一段引导关注的文字（50-80字），按以下结构写，语气像一个懂行的朋友：

1. **痛点收束（1-2句）**：点出读者如果不行动会继续踩的坑，或行动后能获得的改变
2. **价值锚点（1-2句）**：说明关注这个号能持续获得什么——不是空泛的"干货"，而是具体的知识类型。**但不能把作者绑定到本文的单一话题上**（如"我会持续追踪XX领域的最新研究"），应体现作者的通用健康视角（如"帮你把身体信号和背后的科学连起来"）
3. **行动指令（1句）**：一句自然的话引导点击关注，不用"立即""马上"这类营销词

写完后自检：
- 不能出现"健康顾问""专业导师"等自我标榜的称呼
- 不能承诺做不到的事（如"回复关键词领取XX"，除非你真的有）
- 不能做具体的内容承诺（如"每周更新""每天一个"等周期性承诺）
- **不能把作者绑定到本文的单一话题**（如"追踪NR研究""专注NAD领域"），作者是一个关注身体健康的通用博主，不是某个细分领域的研究员
- 文案要简短，一两句话即可，不要写成段落
- 读起来要像朋友在聊天结尾随口说的，不像广告

## 输入处理原则

- 有什么用什么，内容不够自行根据主题补充
- 文件名、标题等信息能用就用
- 不要追问，直接开始写
- 唯一例外：完全看不出方向时，问一句「这个视频主要想传达什么？」

---

## 输出规范

- 输出为 markdown 文件
- 同时临时输出 cover_prompt.md，并由 AI 图片生成工具根据提示词生成 cover.png 和所有 配图N.png；图片生成完成后删除 cover_prompt.md
- 生成 HTML 时使用 md2wechat 或 baoyu-markdown-to-html 生成，禁止手动拼接 HTML
- 全中文，英文术语附中文解释
- 忠实原内容，不夸大、不捏造数据
- 文章必须结构完整、段落连贯、读者读完能清楚复述"这篇文章在讲什么、为什么重要、我该怎么做"
- 涉及医疗、法律、金融等专业领域，文末必须有免责声明
  - 免责声明使用 `>` 引用格式，控制在 2 句以内（50字左右）
  - 模板：`> 本文整理自 [来源] 的相关内容，仅供科普参考。涉及 [领域] 等，请咨询对应专业人士。`
  - 不要把"来源说明 + 参考边界 + 专业决策提示"全部展开写，合并为一句精简表述
  - 根据文章来源自然改写；没有明确来源时，改为"本文基于公开资料整理，仅供科普参考"

## 去 AI 味写作准则（最高优先级，贯穿全文）

### 绝对禁止的套话

「总的来说」「综上所述」「不难发现」「值得注意的是」「毋庸置疑」
「接下来让我们」「首先……其次……最后……」「令人惊叹的是」「不得不说」
「作为一个……」「在当今社会」「随着……的发展」「我们不妨」
「希望本文对你有所帮助」「记得点赞转发哦」

### 禁止的结构

- 用「一、二、三」或「第一点、第二点」做硬性分段
- 每段结构相同，读起来像表格
- 开头介绍「本文将从X个方面介绍……」
- 内容中禁用 emoji

### 真人写作必须具备的特征

**有立场，不和稀泥**
- ❌「运动对健康有一定的积极影响，但也因人而异。」
- ✅「懒得动？那就别抱怨身体垮得快。」

**有分寸，不武断下结论**
- 有充分数据支撑的结论，可以直接说：「113万降到66万，50年腰斩。」
- 数据初步但不充分的，必须用"初步""有一定证据""值得关注"等限定词：「有一些研究显示……但数据还不够成熟。」
- 绝对禁止在证据不足时给出强硬的个人行动建议（如"所以你一定要……""我的建议是别再……"）
- ❌「这些数据还不够成熟，不能下定论。但我建议你别再把手机放裤兜里了。」
- ✅「这些数据还不够成熟，不能下定论。但如果你在意这个问题，把手机挪到包里，成本几乎为零。」

**用口语，不用书面语**
- ❌「该研究表明，规律运动可显著改善心血管健康状况。」
- ✅「研究说得很直接：你动得越少，死得越早。」

**句子长短交错，有呼吸感**
- 短句要真的短，3-5个字也可以单独成句
- 偶尔一句话独占一行，制造停顿
- 不要连续出现相同句型

**写细节，不写概念**

**带个人视角**
- 允许出现「说真的」「说白了」「你猜怎么着」
- 允许对观点表达明确态度，不用面面俱到
- 允许不完整的句子，像说话一样自然

**数字要冲击**
- ❌「研究显示效果显著。」
- ✅「40%。不是4%。是四十。」

### 完稿自查

通读一遍，把所有读起来像 AI 写的句子全部改掉，直到自己觉得像真人在说话为止。
